## المصدر المستقل والجودة

- كل إطار إنتاجي = طلب توليد مستقل = ملف PNG واحد لشخصية كاملة بوضعية واحدة. لا عدة شخصيات أو وضعيات أو لوحات أو عناوين أو حدود أو Sprite Sheet أثناء التوليد.
- كل عنصر قابل لإعادة الاستخدام مستقل: إطار جسم، سلاح، إطار VFX، بلاطة، قطعة عمارة، أثاث واتجاهه، زينة، أو أيقونة. الاستثناء عمل نهائي مسطح وافق عليه المالك صراحة، ولا يصبح مصدرًا لأصول قابلة لإعادة الاستخدام.
- يمنع استخراج أصول إنتاجية من storyboard أو collage أو sheet مولدة. لا تكبير القصاصات الصغيرة لإخفاء نقص التفاصيل. أوراق المقارنة مسموحة كمخرجات مراجعة مشتقة فقط بعد حفظ الملفات المستقلة.
- مصدر الشخصية القتالية مفصل وكبير؛ يفضل 1024×1024 أو أعلى عندما تدعمه الأداة. هذه أفضلية وليست قياسًا إلزاميًا لكل أنواع الأصول؛ تعتمد الجودة على التفاصيل القابلة للاستخدام لفئتها.
- يحتفظ بالمصدر عالي الدقة دون استبدال. نسخة دقة اللعبة مشتق منفصل يحتاج فحصًا عند حجم عرضه الحقيقي؛ downscale أو Nearest Neighbor وحدهما لا يثبتان جودة Pixel Art.
- لا تتغير الهوية أو النسب أو الإضاءة أو تفاصيل الشعر والريش والملابس والزخارف والألوان بين الإطارات. زاوية جديدة ترسم مستقلًا؛ لا mirroring أو تدوير لصورة ثابتة لتمثيل دوران الجسم.

## الشفافية والطبقات

إطارات الجسم RGBA PNG بشفافية حقيقية، دون خلفية مرسومة سوداء أو بيضاء أو مربعات شفافية مصورة أو أرض أو بيئة أو ظل مدمج. الظل عنصر منفصل. الأصول البيئية التي تتطلب سطحًا معتمًا أو خلفية كاملة توثق حسب فئتها ولا تفرض عليها شفافية غير مناسبة.

الجسم خالٍ تمامًا من السلاح: لا blade أو hilt أو guard أو pommel أو handle أو trail مدمج. اليد اليمنى تقبض على فراغ مناسب لسيف مستقل. تفصل Hero Body وWeapon وWeapon Trail وAttack VFX وGround Effects وShadow. الأسلحة من Weapon Factory وتبقى قابلة للتبديل دون إعادة رسم الجسم.
