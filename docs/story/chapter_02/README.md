# الفصل الثاني — التخطيط مفتوح
لم يُحسم أين ينتهي الفصل الأول الموسع، وهل زيارة Silent Gate Forest تكون قبل أو بعد مشهد الضريح. لا تكتب أحداث الفصل الثاني على أنها معتمدة.

**الخط القصصي المؤكد لاحقًا:** الحجاب القديم المحيط بـ Hidden Island يضعف تدريجيًا نتيجة اضطراب السيف والأختام، والجزيرة التي لم تكن مرئية للعالم تعود للظهور ويمكن للآخرين الوصول إليها.

**مشهد مقترح غير معتمد:** بحار على سفينة يلمح أرضًا ظهرت في مساحة من البحر كانت تبدو خالية؛ قائد السفينة يتردد في تصديق ما يرى. لا يعني هذا وصول مستوطنات بشرية إلى الجزيرة في المقدمة.
