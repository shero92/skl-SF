# Ocean Pixel Art Quality Revision

The background now uses a repeated 512×512 cobalt-blue water tile rather than 256×256. Four matching translucent wave textures carry irregular bright-cyan and white foam, with periodic wrap geometry. The Hero Room references them at native on-screen tile size instead of downscaling.

These files replace the previous simpler procedurally generated ocean art in place, retain the same asset IDs and are reusable by other rooms.
