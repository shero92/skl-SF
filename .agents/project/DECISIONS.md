# Material architectural decisions

- **ADR-001 — Single instruction entry:** root `AGENTS.md` is the common project contract. More detailed role/workflow guides live under `.agents/`; no duplicate root `CLAUDE.md` on Claude Code v2.1.277+. Older Claude installations need update or a small optional compatibility bridge.
- **ADR-002 — Task identity:** stable `TASK-####` Markdown record owns status, owner and evidence. The generated task board is a read-only projection; commits/PRs prove actual code changes.
- **ADR-003 — Graphics ownership:** production art belongs to a separate graphics specialist; coding agents only write ART specifications and integrate reviewed outputs.
- **ADR-004 — Art deduplication:** one `ART-####` request per distinct asset need, planned outputs recorded up front; delivered PNGs with hash manifests, quality signoff and map metadata before integration.
- **ADR-005 — Visual QA:** CI can verify files and metadata, not artistic parity. Preserve a real source image and actual Godot render for human comparison.

- **ADR-006 — Owner direct merge policy (2026-10-25):** Tested code may merge automatically into main; no human PR review required for individual code tasks. Each task gets an ephemeral branch and git worktree, exclusive touch paths, max one task per agent, sequential merge lock, full tests before merge and retest+revert on main if regression. Runner stays DISABLED until a supervised real task proves this safe. No task-branch generated indexes; regenerate on main only. This replaces older policy requiring manual PR review.
- **ADR-007 — Local subscription-only planning:** Windows Task Scheduler 08:13/12:13/16:13/20:13 Europe/Berlin; alternating Claude/Codex using existing interactive CLI OAuth, not paid API keys. No GitHub Actions AI or planner task writer. JSON proposals untrusted, validated by deterministic Python. No output when repo/goal/task inputs unchanged. Rate limits yield a persisted cooldown, no retry loops.
- **ADR-008 — Goal-image handling:** GOAL-####/goal.md stores the owner's exact text, optional genuine references restricted to that goal. No scheduled or coding agent may read or generate production images; one initial reference planning review and one end-of-goal visual verification only. Owner approves first milestones (auto_activate=false) and final visual signoff.
