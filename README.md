# skl-SF — Godot 4 RPG map factory

This repository currently contains **48 independent transparent PNG files** generated by the reproducible core-art script:
- 22 draft sandstone and compass floor images
- 16 functional reusable alpha-shadow textures
- 10 dialogue UI and icon images

Catalog: \`map_factory/metadata/asset_index.json\` includes 218 slots total. **170 of them still need genuine art files.** The procedural 48 are a functional first pass, NOT high-quality finished reproductions of the reference illustration.

The workflow \`.github/workflows/generate_core_assets.yml\` automatically generated and committed these PNGs. The script \`tools/generate_core_assets.py\` can regenerate missing procedural files but never overwrites manually authored PNGs.

Run \`scenes/main.tscn\` in Godot 4 for a basic map. The room factory uses the floor texture when present; missing furniture, walls, NPCs etc. deliberately show placeholders.

The next art-production milestone is separate transparent sprites from the reference for walls, architecture, furniture, vegetation, ocean, NPC sprites and portraits; review collision/anchor/shadows and floor tileability before production approval.
