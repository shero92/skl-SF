# ART-0052 — محاولات محفوظة

خمس لوحات معمارية محفوظة وغير مستخدمة بعد توجيه القصة البرية؛ أوامر التوليد تحتفظ بمعرفART-0051 التاريخي قبل تخصيصART-0052 لتجنب طلب عامل الغرفة.

راجعmanifest.jsonللمصادر والبصمات والأوامر والأسباب. owner_approvedالتلقائي منفصل عن الاختيار؛ production_active=false لكل هذه المحاولات. لم يتغير أيmasterولم تستخرج منه قطع.
