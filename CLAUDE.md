# Claude Code entrypoint

Read `AGENTS.md` for shared project rules. For the assigned task, follow `.agents/workflows/TASKS.md` and load only relevant supporting instructions.

For story, dialogue, characters, creatures or battles read `docs/story/INDEX.md` and `.agents/workflows/STORY.md` first.

To generate a map or map graphics read `docs/MAP_GRAPHICS_RULES.md` first.

Use the goal-task-factory skill when planning or recording user requests. Its canonical instructions are in `.agents/skills/goal-task-factory/SKILL.md`.
